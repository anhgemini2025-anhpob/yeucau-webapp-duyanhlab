## ✨ Tính năng nổi bật
1. **Thiết kế Gọn Trên 1 Màn Hình (Single-Screen Bento Layout) & Tương Thích Mọi Thiết Bị**:
   - Hiển thị trọn vẹn trên 1 màn hình máy tính (Laptop/PC) và tương thích hoàn hảo với Điện thoại, iPad, Máy ảnh.
2. **Điền Siêu Tốc Bằng 1 Chạm (Zero-Typing Smart Chips & 6 Mẫu Dự Án)**:
   - Chọn nhanh theo mẫu: *Quản lý Doanh nghiệp / ERP*, *Báo cáo Thuế HKD*, *Trợ lý AI Chuyên gia*, *Bán hàng / Đặt lịch CRM*, *Đào tạo / E-Learning*, *Landing Page Cao cấp*.
3. **Ghi Âm Giọng Nói & Đọc Thành Chữ Tiếng Việt Trực Tiếp**:
   - Thu âm trực tiếp ý tưởng qua Microphone (`MediaRecorder`), nghe lại, tải file âm thanh đính kèm và tự động chuyển giọng nói sang văn bản (`Web Speech API`).
4. **Chụp Ảnh Trực Tiếp Từ Camera / Máy Ảnh & Dán Ảnh (`Ctrl+V`)**:
   - Hỗ trợ mở trực tiếp Camera điện thoại/iPad/máy ảnh (`capture="environment"`) để chụp bản vẽ tay, biểu mẫu giấy, hoặc chụp màn hình giao diện mẫu.
   - Đính kèm các tài liệu sẵn có (`.xlsx`, `.docx`, `.pdf`, hình ảnh...).
5. **In Đúng 1 Trang Giấy A4 & Xuất File PDF Чуẩn A4**:
   - Tự động dàn trang vừa khít **tối đa 1 trang giấy A4** (kể cả hình ảnh chụp đính kèm) khi bấm **In A4** hoặc **Tải File PDF**.
